# Song \(颂\) ：a fork of Lute

Welcome to **Song\(颂\)**.

This project is a fork of Lute. Based on the original Lute framework, Song extends some new capabilities including YouTube media parsing, TTS audio reading, multi‑format document recognition, and comic book reading support. The entire project is built with Vibe Coding.

The project is named **Song**. In traditional Chinese culture, "Song" \(颂\) is one of the three core literary genres in *The Book of Songs*, representing solemn odes and chants used for ritual praise. Coincidentally, it shares an almost identical pronunciation with the English word **song**.

Human civilization has long been trapped by the **Tower of Babel** — the eternal language barrier that divides cultures and isolates communication across humanity. 颂 and Song: this beautiful cross‑lingual homophonic coincidence embodies the core vision of this project: **to break the Babel language barrier, turn words into sound, connect thoughts across different languages, and make reading audible and understanding boundless**.

## Core Features

| Feature | Description |
|---|---|
| **🎬 Multimedia Video & Audio Learning** | Supports real‑time subtitle synchronization for YouTube and other online videos, MP3/M4A audiobook learning, and global TTS voice reading. Audio/video playback progress is precisely linked with clickable words to create an immersive language learning experience. |
| **📑 Multi‑format Document Reading** | Natively supports Mokuro comics, PDF files, and EPUB e‑books. Automatically splits and aggregates EPUB chapters into complete book series. All document formats support inline word lookup and interactive vocabulary hotspot overlay. |
| **📚 Intelligent Library Management** | Enables tag‑based book series aggregation, color‑coded icon filtering, resizable table columns, language freeze/activation, one‑click backup & restore, and in‑context auto‑translation, fully optimizing the library management experience. |
| **📊 Detailed Reading Statistics & Reports** | Features visual reading progress display, mobile mini audio player, and multi‑language syllabus tracking for JLPT / DELE / TOPIK / CEFR. Supports progress visualization and CSV export of unfamiliar vocabulary data. |

## Full Feature Overview
| Feature | Description |
|---|---|
| **Video Subtitle Synchronized Reading** | Supports YouTube and other online video platforms. Automatically splits SRT/VTT subtitle timelines and tokenizes text word by word, synchronizing reading content with video playback in real time. |
| **MP3 / M4A Audiobook Support** | Audiobooks are driven by subtitle files. Audio playback progress aligns accurately with clickable vocabulary, enabling efficient listen‑and‑learn and instant word lookup during playback. |
| **Global TTS Voice Reading** | Built‑in TTS player supports hover pronunciation, one‑click reading, term card voice playback, subtitle narration on pause, and a persistent mini player for mobile devices. |
| **Mokuro / Comic Reading** | Supports import of .mokuro, ZIP, and CBZ comic formats. Overlays clickable text blocks on images, perfectly adapted for raw Japanese manga reading and vocabulary acquisition. |
| **Native PDF Reading Support** | Renders full PDF pages with interactive vocabulary hotspots, supporting direct inline word learning for scanned textbooks and digital documents. |
| **EPUB Chapter Series Aggregation** | Automatically splits EPUB files into independent chapters, applies unified series tags in batches, and aggregates multi‑chapter books on the homepage for unified management. |
| **Book Series Tag Aggregation** | Dedicated book series overview page aggregates multi‑volume and multi‑chapter books via tags, supporting series configuration and batch deletion management. |
| **Book Type Filter UI** | The library list adds color‑coded type icons. One‑click filtering for text, video, audio, comic, and PDF book categories. |
| **One‑Click Backup & Restore** | Visual graphical backup and restore panel supports one‑click full data export and recovery without manual database operations. |
| **Language Freeze / Activation** | Supports one‑click freezing of specific language learning status, retaining all reading records and vocabulary data, and resuming learning at any time. |
| **Resizable Table Columns** | The library table supports free drag‑and‑drop column resizing, adapting to long book titles and multi‑field display for personalized layout customization. |
| **Inline Auto‑Translation** | Automatic term translation during reading with multi‑level fallback mechanisms, reducing learning interruptions and maintaining immersive reading experience. |
| **Visual Reading Progress** | The library homepage displays real‑time progress percentage, automatically marking unread, in‑progress, and completed status for accurate learning progress statistics. |
| **Multi‑Language Exam Progress Reports** | Covers English CEFR, Japanese JLPT, Spanish DELE, and Korean TOPIK. Supports vocabulary progress statistics, unfamiliar word lists, and CSV data export. |

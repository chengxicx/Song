### B. 只有泛化条目、缺细分（35 条里的主要项）

- **助词细分**：に（时刻／着落点／目的／评价基准）、と（比较基准）、を（移动路线）、の（同位／格助词＋の）。
  库里是 `X + に`、`X と Y`、`X + を`、`X + の + Y` 这种一行通吃，教材按用法分行。
  这类**不宜再加数据行**（会与泛化行报同一跨度，触发 audit 的 IoU 冲突），
  更适合在现有行里补「用法说明」小节。
- **敬语体系**：`お／ご＋V＋になる`、`お／ご＋V＋くださる`、`お／ご＋V＋いただく`、
  （さ）せていただく 的泛用形、敬语「自谦／尊他」两张总表。
- **体系性概念**：动词第一连用形、简体句、复合动词（动作阶段）、口语缩略、
  数量词＋动词／数量词＋も。这些教材式总论条目库里没有，属「语法书体例」而非「句型」。

### C. 被标成 skipped 的（能查不能用）

`library_entries()` 里 470 行是 skipped：面板可检索、可阅读，但派生不出匹配规格，
所以**读了也不知道**。上册命中的条目里，`X + は`、`X + が`、`X + を`、`X + に`、
`X + で`、`X と Y`、`X + の + Y`、`Verb-て`、`Verb-た`、`Verb-ない`、
`か（疑问）`、`〜と〜とどちらが〜か` 全是这一类（被手写规则顶掉，或不适合硬匹配）。
这对「覆盖」不影响，但对「读到时能自动标出来」影响很大——上册的句型本来就大半靠手写规则兜。

## 检测层面的两个已知识别边界

1. 库里的行**必须能在自己的例句上命中**才算数（`_load_level` 的派生校验），
   所以「有这条」≠「这句话会被标出来」。
2. 上册大量句型是「助词＋活用」的组合，手写 N5 规则只覆盖了最常用的十几个
   （が／から／で／ている／てください／たい／ほしい／好き嫌い／がいます／があいます…），
   其余靠数据行派生规格，精度低于手写规则。

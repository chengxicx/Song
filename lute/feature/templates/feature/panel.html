Install a plugin

Install from a PyPI package name (e.g. lute3-storygen), a pip URL, a path on this server, or by uploading a local folder with Browse… (the folder is uploaded to this server and installed there — this is the way to install when Lute runs on a remote host). Reinstalling a plugin with the same name overwrites/updates it. The plugin takes effect after you restart Lute.

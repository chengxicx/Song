Install a plugin

Supported formats — enter one of these in the box and press Install:

  • PyPI package name — e.g. lute3-storygen, lute3-cantonese, lute3-thai. Parser plugins (cantonese / thai / mandarin / khmer) are detected by name and installed as language parsers; everything else is installed as a feature plugin.
  • pip URL — a Git / HTTP archive URL, e.g. git+https://github.com/user/repo.git or https://host/pkg.tar.gz.
  • Path on this server — a source directory containing pyproject.toml, e.g. /opt/plugins/lute-storygen.

Upload — for remote hosts, pick one of the buttons below instead of typing a path: Folder… uploads a whole source folder, Zip… uploads a .zip archive of the plugin package. The upload is installed on this server; no server-side path is needed.

Reinstalling a plugin with the same name overwrites/updates it. The plugin takes effect after you restart Lute.

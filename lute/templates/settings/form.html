Japanese
{{ form.mecab_path.label }}

Lute uses MeCab to parse Japanese, so MeCab needs to be installed on your machine (see notes in the manual).

Lute includes the Python library natto-py to interact with MeCab. natto-py can usually find MeCab automatically, but you may need to set the MECAB_PATH, per the manual.

Try different values for MECAB_PATH, including leaving the field blank, until clicking the "test" button returns a "success" message.

 {{ form.mecab_path(class="form-control") }}
{{ form.japanese_dict.label }}

Lute supports two MeCab dictionary types: IPADIC (older, widely used, default) and Unidic (newer, more accurate for modern Japanese).

Set to "Auto-detect" and Lute will figure it out automatically based on your installed MeCab dictionary. Only set it explicitly if auto-detection is wrong.

Changing this only affects how readings (pronunciation) are extracted. Tokenization always works regardless of dictionary type.

Sudachi (alternative Japanese parser)
{{ form.japanese_sudachi_dict.label }}

SudachiPy is an alternative Japanese morphological analyzer, independent of MeCab. It offers three dictionary sizes: Small (fastest, basic vocabulary), Core (balanced, recommended), and Full (largest, most coverage).

To use Sudachi, install the sudachipy and sudachidict_<size> packages, then select "Japanese (Sudachi)" as the parser type for your Japanese language.

These settings do not affect the MeCab parser.

 {{ form.japanese_sudachi_dict }}
{{ form.japanese_sudachi_mode.label }}

Sudachi split modes control how aggressively text is segmented:

  • A (shortest) — finest granularity, breaks compounds into smallest units.
  • B (middle) — balanced, good for general use.
  • C (longest) — coarsest, keeps compounds intact (recommended for language learners).

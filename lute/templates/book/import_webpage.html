Import a YouTube video with its subtitle (SRT / VTT) file. The subtitles become the book text, so you can read and look up words while the video plays.










Import a Bilibili video with its subtitle (SRT / VTT) file. The subtitles become the book text, so you can read and look up words while the video plays.










Import an MP3 or M4A audio file with its subtitle (SRT / VTT) file. The subtitles become the book text, so you can read and look up words while the audio plays.












Import a Mokuro manga archive (generated with mokuro) as a .zip or .cbz file. The comic pages are shown with the extracted text blocks overlaid, so you can look up words exactly like in a normal book. (Sample: hanabira_manga_01.mokuro packaged as a zip.)

2026-07-31: PWA installability fixes (v3.10.3.4). Robust SW cleanup that waits for stale SW unregistration before re-registering. Ensures only one active SW per origin. 2026-07-31: PWA installability fixes (v3.10.3.3). Added required 144×144, 192×192, and 512×512 PNG icons with purpose: "any"; separate purpose: "maskable" icons added (no more discouraged "any maskable" combined purpose). Added desktop and mobile PWA screenshots with correct form_factor. SW registration script now has data-cfasync="false" to prevent Cloudflare Rocket Loader from deferring it. Manifest route serves with correct MIME type; cache bumped to v3.10.3.3.

2026-07-31: PWA fixes for installability. Manifest is now served with correct application/manifest+json MIME type via /manifest.webmanifest and loaded with crossorigin="use-credentials" (compatible with BasicAuth-protected sites). Service worker registration now unregisters any stale SWs registered on credential-containing URLs, then registers cleanly against the real origin. Also added richer manifest fields (id, display_override, shortcuts, maskable icons), plus additional meta tags for iOS/Android home screen installation.

2026-07-31: Add PWA (Progressive Web App) support. Lute can now be installed to the home screen on mobile and desktop, with offline caching of static assets and pages for reading without a network connection. Added web manifest, service worker, and theme color metadata.

2026-07-31: Edit book now allows editing the entire article text. The Edit Book form (accessible from the home page Actions menu) now includes a full text area pre-populated with the book's content, along with text file upload, split-by, and words-per-page controls. Changing the text re-parses and re-paginates the book; if the text is unchanged, existing pages and reading progress are preserved.
